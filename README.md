PROJET FINAL : ELDEN PY - BOSS RUSH
-----------------------------------
Auteur : [TON NOM ICI]
Langage : Python 3
Bibliothèque : Pygame

DESCRIPTION :
Elden Py est un jeu de combat de type "Boss Rush" en 2D. 
Le joueur doit vaincre un sorcier évolutif en gérant son endurance et ses esquives.

INSTALLATION & LANCEMENT :
1. Assurez-vous d'avoir Python et Pygame installés :
   pip install pygame

2. Le dossier doit contenir :
   - main.py (Le code source)
   - Les dossiers d'images (img, boss, etc.)
   - Les fichiers sons (.mp3)

3. Lancez le jeu :
   python main.py

FONCTIONNALITÉS CLÉS (Respect des TP) :
- Programmation Orientée Objet (Classes Boss, Joueur, Particule...)
- Gestion des Listes & Boucles (Particules, Projectiles)
- Chemins relatifs (os.path) : Le jeu fonctionne sur n'importe quel PC.
- Gestion des états : Menu, Jeu, Game Over, Victoire.

COMMANDES :
- DÉPLACEMENT : Flèches ou ZQSD
- SAUT        : Espace
- ATTAQUE     : E
- DASH (Esquive): Shift Gauche (Invincibilité temporaire)
- VOLUME      : + / -  (M pour couper le son)
